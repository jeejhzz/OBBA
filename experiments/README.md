# 실험본 보관함

여기 있는 파일은 **사이트에서 쓰이지 않는다.** 시도해 본 것을 버리지 않고 남겨두는 곳이다.

## gemini-llm-version.html

Gemini 로 만들어 본 "진짜 LLM 을 붙인" 버전. 브라우저에서 바로 OpenAI API 를 호출한다.

**왜 사이트에 쓰지 않았나**

1. **API 키가 공개된다.** 정적 사이트라 페이지 소스에 키가 그대로 노출되고,
   누구든 꺼내서 남의 요금으로 쓸 수 있다. 키를 숨기려면 작은 중계 서버가 필요하다.
2. **추천이 근거를 잃는다.** LLM 이 자기 지식으로 제품을 말하므로, 우리가 상품마다 붙여둔
   피부타입·상황·제형 태깅과 가격·링크가 쓰이지 않는다. 없는 제품을 말하거나
   단종된 제품을 권할 수 있고, 올리브영으로 연결되는 링크도 만들 수 없다.

**그럼 LLM 을 쓰려면**

말을 이해하는 일만 LLM 에 맡기고, 제품을 고르는 일은 지금 엔진이 그대로 하는 구조가 답이다.

```
"피부 완전 난리 났어"  →  LLM(통역)  →  { 고민: 진정 }  →  지금 추천 엔진  →  실제 상품 3개
```

이러면 LLM 이 상품 이름을 말할 일이 없어 지어낼 수가 없고, 비용도 문장 하나 값이며,
LLM 이 실패하면 지금의 키워드 방식으로 자동 폴백된다. (docs/ROADMAP.md P2 참고)
