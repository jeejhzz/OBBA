# 상품 목록을 스프레드시트로 관리하기

가격은 세일마다 바뀌고 상품은 계속 늘어난다. 그걸 코드에 박아두면 바꿀 때마다 개발이 필요하다.
시트를 읽게 해두면 **시트만 고쳐도 앱에 반영된다.**

## 열(칸) 설명

| 칸 | 필수 | 뭘 적나 |
|---|---|---|
| 고유번호 | | 비워두면 자동 생성. **이미 있는 상품은 절대 바꾸지 말 것** (장바구니가 이 번호로 기억한다) |
| 사용여부 | | `Y` 또는 비움 = 사용. `N` = 목록에서 숨김 |
| 브랜드 | ✅ | 카드에 크게 표시된다 |
| 제품명 | ✅ | 용량까지 적어주면 좋다 (예: `자작나무 수분 크림 80ml`) |
| 단계 | ✅ | 클렌징 / 토너 / 토너패드 / 에센스 / 세럼 / 마스크팩 / 패치 / 로션 / 크림 / 미스트 / 슬리핑팩 / 선크림 |
| 정가 | ✅ | 숫자만 (예: `32000`) |
| 판매가 | ✅ | 숫자만. 할인율은 정가와 비교해 자동 계산된다 |
| 올리브영링크 | | 상품 페이지 주소를 그대로 붙여넣으면 상품번호를 알아서 뽑아낸다. 검색 링크여도 된다 |
| 제형 | ✅ | 가벼움 / 보통 / 쫀쫀함 — **"가벼운 수분타입 vs 쫀쫀한 영양타입" 추천에 쓰인다** |
| 피부타입 | | 건성 / 지성 / 복합성 / 민감성 / 수부지 / 보통, 여러 개면 `/`로. 비우면 모든 피부 |
| 고민 | ✅ | 수분 / 진정 / 미백 / 결 / 탄력 / 피지, 여러 개면 `/`로 |
| 상황 | ✅ | 데이트 / 야근 / 여행 / 데일리, 여러 개면 `/`로 |
| 이런분께 | | 비교 화면에 그대로 나온다. 비우면 피부타입으로 대신 채운다 |
| 핵심포인트 | | 카드에 한 줄로 나온다 |
| 태그 | | `#수분폭탄 #화장찰떡` 처럼 띄어쓰기로 구분 |

**필수 다섯 칸(브랜드·제품명·단계·판매가·고민·제형·상황)이 비면 그 줄은 건너뛴다.**
없는 값을 앱이 지어내는 것보다 빼는 게 낫기 때문이다. 건너뛴 줄은 브라우저 콘솔에 이유가 찍힌다.

## 시트를 앱에 연결하기

1. 구글 시트에서 **파일 → 공유 → 웹에 게시**
2. 형식을 **쉼표로 구분된 값(.csv)** 으로 선택하고 게시
3. 나온 주소를 `assets/js/data/source.js` 맨 위 `OBBA.SHEET_CSV_URL` 에 붙여넣기

이후로는 시트를 고치면 앱을 새로 열 때 반영된다. 배포도, 개발자도 필요 없다.

## 안전장치

- 시트를 못 읽으면(오프라인, 주소 오류, 느림) **조용히 내장 목록으로 돌아간다.** 상담이 끊기지 않는다.
- 시트는 내장 목록을 지우는 게 아니라 **합친다.** 고유번호가 같으면 갱신, 없으면 추가.
  그래서 상황×고민 16조합 큐레이션이 그대로 살아있다.
- 아티팩트(claude.ai 링크)에서는 외부 주소를 못 읽어서 항상 내장 목록을 쓴다.
  시트 연동은 GitHub Pages 주소에서 동작한다.

## 목록을 새로 받았을 때

`카테고리 / 브랜드 / 제품명 / 추천대상_피부고민 / 핵심포인트 / 상품링크` 형식으로 정리된 목록이 있으면
변환기를 돌려서 위 형식으로 바꿔준다.

```
node tools/import-list.js docs/incoming/<파일>.csv   →  docs/catalog-import.csv
```

카테고리→단계, 피부고민→고민/피부타입, 링크→상품번호는 자동으로 변환된다.
**가격·상황·제형은 자동으로 채우지 않는다.** 추측해서 넣으면 틀린 값이 조용히 들어가기 때문이다.
