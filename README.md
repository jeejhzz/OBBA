# OBBA (Oliveyoung Beauty Browser Assistant) 💄

올리브영의 방대한 제품 데이터 중 사용자의 **'상황'**과 **'피부 고민'**에 맞는 베스트셀러를 매칭해주고 1:1 비교 솔루션을 제공하는 대화형 챗봇 프로토타입입니다.

## 🚀 주요 기능
* **상황/고민별 맞춤 큐레이션:** 데이트, 야근 등 라이프스타일 상황과 수분, 트러블 등 피부 고민을 조합하여 최적의 제품 추천
* **모바일 최적화 스와이프 UI:** 여러 제품을 가로 스크롤(Swipe)로 편리하게 탐색
* **1:1 비교 팩트체크:** 추천된 제품들의 타겟 고객과 핵심 소구점을 한눈에 비교할 수 있는 표 제공
* **자연어(NLP) 시뮬레이션:** '복합성' 등 특정 키워드 입력 시 뷰티 전문가 페르소나의 맞춤형 답변 제공
* **Direct 쇼핑 연동:** 마음에 드는 제품 클릭 시 올리브영 실제 검색/상세 페이지로 즉각 랜딩

## 🛠️ 기술 스택
* **HTML5 / CSS3 (Tailwind CSS)**
* **Vanilla JavaScript** (단일 파일 구조로 외부 라이브러리 의존성 최소화)
