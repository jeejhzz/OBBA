# OBBA — Oliveyoung Beauty Browser Assistant

> 상황과 피부 고민만 고르면, 올리브영에서 뭘 사면 되는지 골라주는 모바일 대화형 어시스턴트.

올리브영에는 제품이 너무 많다. OBBA는 "지금 나한테 필요한 거 3개"까지 좁혀주는 걸 목표로 한다.

```
$ npx http-server -p 8137 .     # 또는 python3 -m http.server 8137
$ open http://127.0.0.1:8137
```
빌드 도구 없이 정적 파일만으로 동작한다. (GitHub Pages에 그대로 올릴 수 있음)

## 무엇을 하는가

1. **피부타입 → 상황 → 고민** 3단계 질문. 각 단계는 버튼 한 번 또는 자연어 한 줄로 넘어간다.
   - `"나 지성인데 야근하고 와서 트러블 났어 가성비로 추천해줘"` → 세 축을 한 번에 파싱해서 바로 추천으로 점프
2. **추천 카드 3장**을 가로 스와이프로 제시. 각 카드에는 왜 골랐는지가 칩으로 붙는다
   (`오빠 픽` / `지성 피부에 잘 맞음` / `1만원 이하 예산 OK`).
3. **비교 뷰**에서 가격·타깃·핵심 성분·제형을 나란히 놓고, 프로필 기준으로 결론을 낸다.
4. **제형 취향**(가벼움/쫀쫀함)을 고르면 즉시 재추천 — 취향이 다음 대화에도 계속 남는다.
5. **장바구니**는 루틴 순서(클렌징 → 토너 → 세럼 → 크림 → 선케어)로 정렬되고,
   정가 대비 절약액을 보여주며, 매장에서 볼 수 있게 텍스트 리스트로 복사된다.

프로필과 장바구니는 `localStorage`에 남아서, 다시 들어와도 오빠가 나를 기억한다.

## 구조

```
index.html                 화면 뼈대만. 로직 없음
assets/css/obba.css        색·레이아웃·모션 (유틸리티는 Tailwind CDN)
assets/js/
  data/catalog.js          상품 21종. 연동 어댑터가 채울 스키마의 로컬 구현체
  data/flows.js            상황/고민/피부타입/예산 축 + 큐레이션 16조합 + 자연어 사전
  core/store.js            프로필·장바구니 (localStorage, 실패해도 대화는 계속)
  core/engine.js           추천 엔진: 큐레이션 + 스코어링 하이브리드
  ui/render.js             HTML 빌더. 사용자 입력은 전부 esc() 통과
  app.js                   대화 컨트롤러 + 이벤트 위임
```

### 추천이 만들어지는 방식

**큐레이션(사람) + 스코어링(개인화)** 하이브리드다.

- 상황×고민 16조합에는 사람이 쓴 코멘트와 대표 상품이 항상 붙는다 → 말투와 근거의 품질을 보장
- 그 위에서 프로필로 점수를 매겨 순서를 바꾸고, 후보가 부족하면 카탈로그에서 보강한다

```
고민 일치 +30 · 상황 일치 +15 · 피부타입 일치 +25(불일치 −20)
제형 취향 일치 +15(정반대 −10) · 예산 이내 +10(초과 −25) · 30%↑ 할인 +8 · 큐레이션 +20
```

같은 "데이트 × 수분"이라도 지성이면 토리든 세럼이, 건성이면 에스트라 크림이 1번 카드로 온다.
점수와 함께 **사람이 읽을 수 있는 이유**를 같이 리턴하기 때문에 UI가 근거를 그대로 보여줄 수 있다.

## 올리브영 연동

지금은 **딥링크 방식**이다. 상품번호(`goodsNo`)가 있으면 상세페이지로, 없으면 검색 결과로 보낸다.
카탈로그 스키마만 지키면 데이터 출처는 나중에 통째로 갈아끼울 수 있다.
선택지별 장단점과 이행 계획은 [docs/OLIVEYOUNG-INTEGRATION.md](docs/OLIVEYOUNG-INTEGRATION.md) 참고.

## 알려진 제약

- 가격/할인율은 **하드코딩된 스냅샷**이라 실제 올리브영 판매가와 다를 수 있다. 실시간 가격은 연동 이후.
- Tailwind·Font Awesome·Pretendard를 CDN에서 받는다. 오프라인이나 CDN 차단 환경에서는 레이아웃이 깨진다.
  (로드맵 P1: 정적 파일로 내재화)
- 자연어 인식은 형태소 분석 없이 키워드 부분 문자열 매칭이다. 사전에 없는 표현은 버튼 흐름으로 유도한다.
